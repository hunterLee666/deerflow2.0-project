# Development Scripts

This directory contains scripts for development tasks.

## Script Categories

1. **Dev** (`dev/`): Development environment setup and management
2. **Build** (`build/`): Build and compilation scripts
3. **Deploy** (`deploy/`): Deployment automation scripts
4. **Test** (`test/`): Testing automation scripts

## Common Scripts

- `setup.sh`: Initialize development environment
- `run-dev.sh`: Start development servers
- `run-tests.sh`: Run test suite
- `lint.sh`: Run code linting
- `format.sh`: Format code
