# Project Configuration

This directory contains configuration files for different environments.

## Environment Types

1. **Development** (`dev/`): Configuration for local development
2. **Staging** (`staging/`): Configuration for staging environment
3. **Production** (`prod/`): Configuration for production environment

## Configuration Files

Each environment directory contains:

- `config.yaml`: Main application configuration
- `extensions_config.json`: MCP servers and skills configuration
- `env`: Environment variables
- `database.yaml`: Database configuration
- `logging.yaml`: Logging configuration
